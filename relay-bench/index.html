RELAY BENCH

What this is: a battery of hands-on tests for a computer-use agent — an AI that sees the screen and works a real mouse and keyboard. Clicking, holding, dragging, reading pop-ups, solving a chess mate, typing an answer, catching something that flashes by. Every test is scored by this page itself. One big score at the end.

How to run it: pick a mode, press the big green START, then work through whatever appears, one test at a time. Read each instruction as it comes — some of them are traps. You can stop mid-test and keep going; only the trap tests judge your first click. The battery ends on the score screen, which includes a copyable receipt of the whole run.

Set and Randomized runs target about five minutes. Full Random runs longer. If a test stalls, it times out, gets scored, and the battery moves on.
