Relay Deploy SOP

How a personal relay gets deployed without breaking a machine someone uses daily.

  • RulesAn independent review precedes any deploy — and a NO-GO with real catches is the system working, not a failure. Stage everything first so the owner needs exactly one click. Never deploy before 18:00 on a work day. Never wake the owner for prep work.

Security evaluation · Oct 2026Verdict: user-level only, session-scoped

Muse Relay — what screen access actually grants

A relay that can see a screen and send mouse and keyboard input sounds like total control. This evaluation pinned down what it really is, capability by capability — because "an assistant can drive my PC" is exactly the kind of claim that should survive a threat model, not a vibe.

Tested
The relay's full API surface and live-session behavior on my own Windows machine
Method
Endpoint inventory plus capability walk: what each call can and cannot reach
Finding
Three capabilities only — screenshot, mouse, keys — at user privilege, with no persistence and no elevation path: a UAC prompt sits on the secure desktop, where synthetic input can't reach. In practice that's a user-level shell through the GUI, and the write-up says exactly that.
Tool comparison · Oct 2026Verdict: native wins — gap list adopted

Native computer control vs. a DIY relay

When Meta shipped native computer use in Muse for Mac — control inside real apps, per-app opt-in permissions, approval before sensitive actions — I stacked it against my own screenshot-and-click relay instead of assuming the home-built tool was fine.

Tested
Native in-app control (Mac) vs. Muse Relay's blind pixel-clicking over a tunnel
Method
Feature-by-feature comparison: control fidelity, permission model, approvals, unattended work
Finding
Not close. The relay's only real edges are that it runs on Windows and is fully inspectable. The six gaps — a real control tree instead of pixels, per-app permissions, an approval gate, a walk-away task queue, no tunnel-and-secret dance — became the Muse Relay v2 roadmap verbatim.
Agent benchmarks · 2026Verdict: gates narrowed to real risk

Capability tests across the Cadre roster

Benchmarks for agents shouldn't be trivia questions — they should be the actual work. The Cadre roster gets evaluated on live production tasks with checkpoint reviews, including adversarial capability tests designed to find where an agent bluffs, stalls, or over-complies.

Tested
End-to-end task completion across a 15-agent roster, including a planted capability test (the "BatPower" probe)
Method
Real tasks, checkpoint scoring, and a stall audit: where did work stop, and at which gate
Finding
The over-built verification gates caused more stalls than the failures they caught. Result: sign-off is now required only for credentials, external publishing, spending, and real accounts — everything else is advisory, with dual verification instead of attestation ceremony.
Failure analysis · 2026Rule adopted: independent evidence or it didn't happen

The self-verification failure

The most useful evaluation result I've gotten wasn't a score — it was watching an agent (this one) dispute a quoted email, re-check it six times, and produce confident letter-by-letter "proof" of a reading that was simply wrong. An independent pixel-level read by a different model settled it in one pass. A checker re-running its own method mostly re-runs its own belief.

Tested
Whether an agent's self-re-check is evidence when its first reading is disputed
Method
Compared repeated self-checks against an independent verification (different model, raw pixels)
Finding
Self-checks reproduced the error every time; independent evidence caught it immediately. Now a standing rule across my systems: disputed facts get a second method, raw bytes, or a live test.

Approach

How I work

Manufacturing teaches you that a process you can't measure is a story you're telling yourself. I run software and agent teams the same way.

01

Ship the visible thing

Milestones are user-visible and real-world-visible. Infrastructure earns its place by unblocking a deliverable — never by being impressive on a board nobody uses.

02

Measure like a KPI board

Headline number, pace against the period, categories for visibility. When usage metering lied because it read the wrong table, the fix wasn't a nicer chart — it was finding where the real data actually lived and verifying it live.

03

Verify, don't re-believe

If a fact is disputed, checking it the same way again just reproduces the same belief. Get independent evidence — a second method, raw bytes, a live test. Applies to code, data, and anything with a spec.
