    01

    A circuit that decides itself

    Every square on the grid starts undecided. The number in it is how many tiles it could still become — 12 at the start, because nothing has been placed yet.

    Each step, the model picks the square with the fewest options left (it wears the copper ring), settles it on one tile, and then tells its neighbours. Any neighbour tile whose edge would no longer meet cleanly is struck off, and those squares flash as their numbers drop. Then it looks for the tightest square again.

    Watch the ring. It never wanders into open space while a squeezed square is waiting — it works outward from what is already decided, like someone finishing a crossword from the letters they already have. When the last number is gone, every line on the grid meets a matching line or runs off the edge.

    02

    How the model is built

    Tiles. Each tile has four edges, and each edge is either a connector or empty. Of the sixteen ways to set four edges, the model uses the twelve that are not dead ends: one blank, two straights, four corners, four tees and one crossing. The Pipes set drops the blank and keeps eleven. Both are drawn in the legend on the grid.

    The rule. Two tiles may sit side by side only if their facing edges match: connector meets connector, empty meets empty. Nothing else limits where a tile can go. The outer border is open; any edge may face it.

    The loop. Every cell starts with every tile in the set possible. Then, repeatedly:

    1. Find the uncollapsed cells with the fewest remaining options. If several tie, pick one of them uniformly at random.
    2. Collapse it to one of its remaining options, chosen uniformly at random.
    3. Propagate: for each neighbour of a cell that just changed, strike every tile that no longer has a compatible partner across the shared edge. A neighbour that lost anything is checked in turn, until nothing changes.

    Entropy (readout) = mean of log₂(options) over the uncollapsed cells, in bits. Start: log₂ 12 ≈ 3.58 bits. A cell with one option left adds 0. Done: 0.

    Randomness. All three random choices — the tie, the tile, the next seed — come from one seeded generator (mulberry32). The seed in the controls is always the current attempt's; type one in to replay that pattern exactly. Opening the page or pressing New pattern takes a fresh seed from your browser's own random source.

    Contradictions. If propagation ever empties a cell, the Phase readout says Contradiction, the counter goes up by one, and the empty cell is marked in red. The grid holds for two and a half seconds; then a new attempt starts on a seed drawn from the same generator. A finished pattern holds for the same beat before the next one, and both restarts can be switched off.

    What we measured. We ran this exact code 8,000 times: seeds 1 to 1,000 at every grid size, with both tile sets. It produced no contradictions, and every finished grid had zero mismatched edges. That result is about these tile sets, not a promise about wave function collapse in general. With all twelve tiles, no step narrowed anything beyond the four neighbours of the cell it settled. With Pipes, about one step in twenty-two reached two cells out: without a blank, a cell facing empty edges on any two sides has only one tile left, and settling it narrows the cells beyond it.

    Counters. New pattern — or a new size, tile set or seed — starts a new session: fresh grid, Collapsed back to 0, Contradictions and attempts back to zero, Phase back to Live. Automatic restarts keep the session's counts.

    03

    Where this shows up

    Games and generated worlds. Maxim Gumin published the WaveFunctionCollapse algorithm in 2016, building tile maps and textures from small examples. Game makers took it up quickly; Oskar Stålberg's work on Bad North and Townscaper is the best-known case of it shaping places people walk around in.

    Puzzles you already solve this way. Filling in the square with the fewest candidates first is how most people do Sudoku. Constraint-solving textbooks call it the minimum remaining values heuristic. Striking candidates from neighbours until nothing changes is constraint propagation, the same family as the arc-consistency methods in those books.

    The name is a borrowed picture. Nothing quantum happens here. "Collapse" borrows the image of something held in many states settling into one when it is looked at. Here, the looking is a random draw, and the settling spreads to the neighbours.

    A study page. The model runs entirely in your browser; nothing is sent anywhere.
