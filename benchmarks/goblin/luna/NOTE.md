# Goblin Luna — build note

Built procedurally in Blender 4.5.14 with a Python scene-generation script. The character is assembled from smooth anatomical meshes, shaped tapered forms and curves, with separate sculptural facial features, layered armor, leather straps, stitched cloth, and a small dagger. Materials distinguish moss-green skin, oxblood fabric, worn leather, brass, tempered steel, ivory, and amber eyes.

The character stands on a matte neutral-gray studio floor, against a gray world, framed by a three-quarter orthographic camera. Lighting uses a warm large key, cool fill, warm rear rim, and a soft face catchlight.

- Render engine: Cycles
- Samples: 64, denoising enabled
- Output: 1920 × 1080 PNG, AgX Medium High Contrast
