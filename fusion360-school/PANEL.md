# The blind panel — judging CAD work

Gate 2 for every rung. Measured bars can't see "that fillet reads wrong" or "no human would model it like that." Judges can — if you run them cold.

## The standard render set (the builder delivers these, same every time)

1. Isometric, front-left, shaded with edges
2. Isometric, back-right, shaded with edges
3. Top view, shaded
4. One section view through the part's most important feature
5. For assemblies: one render at each joint's limit position

Same views, same style, every attempt — comparisons only mean something when the camera doesn't move.

## The protocol

- **Three judges, same model, fresh sessions, no shared context.** Each sees only the render set (plus the reference renders, on match exercises). Never the builder's report, never prior scores.
- **The bare prompt** — do not decorate it:

> Here are renders of a CAD model. Grade the modeling as if a human made it, 0–10, where 5 is a competent beginner and 10 is professional work. Give your score and your reasons. Note anything that reads as wrong, implausible, or not how a person would model it.

- **Gate: panel mean ≥ 5.0**, and Gate 1 passed. Both.
- **Convergence is the diagnosis.** Faults named by ≥ 2 judges go in the record verbatim — they design the foundation drill if the rung fails.
- **Splits are weak evidence.** 7/4/4 means the work is ambiguous, not good. Record it whole.
- **Owner is appellate.** The human can overrule the panel either way; the overrule is recorded next to the panel record, never instead of it.

## Anti-patterns

- **Priming** ("flag anything that looks AI-made") — manufactures false positives on honest work.
- **Showing judges the self-assessment** — the panel collapses into agreeing with it.
- **Reusing judge sessions** — fresh every time; a judge with history has favorites.
- **Editing panel records** — they're the lesson source. Keep them whole, including the sting.

## The discrimination variant

For design picks (which of two variants is better / which matches the reference): **5 judges, majority vote, constrained answers only.** Judges' free-text descriptions are inadmissible — votes are evidence, descriptions confabulate. A 3–2 split is a weak result; say so.
